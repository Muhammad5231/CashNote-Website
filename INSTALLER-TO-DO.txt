BEFORE YOU SHARE CASHNOTE WITH OTHER USERS

1. Build and test the Windows Setup EXE from the CashNote desktop project.
2. Create a public GitHub Releases repository (default: Muhammad5231/CashNote-Releases).
3. Publish a GitHub Release and upload the Setup EXE with a name like:
   CashNote-Setup-1.3.1-Windows-x64.exe
4. Confirm GITHUB_OWNER and GITHUB_REPO on the Render cashnote-download-api service.
5. The website reads the official GitHub asset download_count and routes Windows desktop visitors through the device-check gateway.

Do NOT put the installer inside public/. Do NOT publish win-unpacked/ or CashNote.exe alone.
The download number counts release asset downloads, not unique people or successful installations.
