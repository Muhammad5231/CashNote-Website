A few useful answers

Before you begin.

Is CashNote a web app or a desktop app?

CashNote is a Windows desktop application. This website introduces the product and provides the installer when it is published.

Does CashNote connect to my bank?

No bank connection is required. You add and manage your income and expense records manually.

Are my records uploaded to the cloud?

CashNote is designed for local storage on your computer. It does not require a CashNote cloud account or cloud sync.

Can multiple people use CashNote on one computer?

Yes. CashNote supports separate local profiles with individual usernames and PINs, so each profile can keep its own finance workspace.

Can I export my records?

CashNote supports CSV and PDF report exports, along with a local JSON backup workflow.

Can I use CashNote on a phone?

CashNote is currently a Windows desktop application. You can browse this website on a phone, but the Windows installer is only offered on Windows desktop computers.

What does the download number mean?

The count is read from GitHub's public release asset download totals. It sums downloads of CashNote installer assets across the latest 100 published releases; repeat downloads count separately. It does not identify unique people or confirm that the app was installed.
