A few useful answers

Before you begin.

Is CashNote a web app or a desktop app?

CashNote is a Windows desktop application. This website introduces the product and provides the installer when it is published.

Does CashNote connect to my bank?

No bank connection is required. You add and manage your income and expense records manually.

Are my records uploaded to the cloud?

CashNote is designed for local storage on your computer. It does not require a CashNote cloud account or cloud sync.

Can multiple people use CashNote on one computer?

Yes. CashNote supports separate local profiles with individual usernames and PINs, so each profile can keep its own finance workspace.

Can I export my records?

CashNote supports CSV and PDF report exports, along with a local JSON backup workflow.

Can I use CashNote on a phone?

CashNote is currently a Windows desktop application. You can browse this website on a phone, but the Windows installer is only offered on Windows desktop computers.

What does the download number mean?

The count is read from GitHub's public release asset download totals. It sums downloads of CashNote installer assets across the latest 100 published releases; repeat downloads count separately. It does not identify unique people or confirm that the app was installed.

Does the website always download version 1.9.7?

The download service always redirects to the latest matching Windows Setup file actually published in the configured public GitHub Releases repository. The website describes CashNote v1.9.7, but that installer will only be served after the matching v1.9.7 Setup asset is published.

Is CashNote AI required?

No. AI is optional. The normal finance workspace works without an AI provider. To use CashNote AI, add an API key from a supported OpenAI-compatible provider and connect to the internet.

Does CashNote AI send my financial data online?

Only when you choose to use AI. Your prompt and relevant finance context are sent to the provider configured in the app. Review that provider's privacy terms and pricing. Normal local finance features do not require a cloud account.

Can AI change my records on its own?

No. CashNote AI prepares a proposal, asks questions when important information is missing, and requires your confirmation before a supported change is saved.

Where is my CashNote data folder?

Current Windows releases use the CashNote folder in your Windows AppData Roaming location. When upgrading from the older Nivora-branded storage, CashNote includes a migration process to preserve existing local profiles and records.
