05 · LOCAL DATA & PRIVACY

Your records stay
on your computer.

CashNote does not require a cloud account, bank login or financial-service connection for normal manual finance tracking. Its current Windows storage location uses the CashNote-branded folder in your user AppData location.

WINDOWS USER DATA LOCATION%APPDATA%\CashNote Current branded storage folder
  • Local JSON backup export
  • Old Nivora data migration support
  • Separate local profile workspaces
⌂IMPORTANT PRIVACY DISTINCTION

Local storage and AI are separate choices.

Your finance records are stored locally. When you deliberately send a request to CashNote AI, the prompt and relevant finance context are sent to the AI provider you configured.

Financial data is not encrypted at rest in the current application. A local PIN is an app-level lock, not disk encryption. Protect your Windows account and keep backups somewhere you control.
