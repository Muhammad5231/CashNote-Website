CASHNOTE WEBSITE v2.5 — FULL UI, MEDIA & ADMIN CMS UPDATE

- Rebuilt the GitHub download counter card with a compact editorial metric treatment, live-source label, animated bar motif and better mobile layout.
- Added a responsive product-tour section. If no product video has been uploaded, a custom animated CSS motion graphic remains visible. Uploading MP4/WEBM automatically replaces the fallback with the player.
- Added a screenshot gallery with actual CashNote transaction, profile and preferences screenshots, refined captions, hover motion and mobile stacking.
- Added a private website admin at /admin/ for editing homepage copy, Features/About headings and tour caption.
- Admin can upload/replace the product tour poster, product video and all three screenshots. It can export/restore editable text content JSON; uploaded media remains on the persistent disk.
- Added secure signed HttpOnly admin sessions, same-site cookie, origin checks, login throttling, file size/type/signature validation and server-generated upload names.
- Content and media are stored as JSON/files on a Render Persistent Disk. No external database required.
- Updated Render blueprint to use Starter API service and 1 GB persistent disk; this is paid Render infrastructure. Free Render filesystem is ephemeral and is not suitable for durable CMS edits.
- Added FAQ structured data, organization structured data, updated sitemap and blocked /admin/ from indexing.
- Preserved existing GitHub release download counter, Windows-only download gate and separate static website/API architecture.

IMPORTANT: Set ADMIN_PASSWORD (16+ characters) in Render before using the admin panel. ADMIN_SESSION_SECRET (32+ characters) is generated by the Render blueprint. See ADMIN-SETUP-GUIDE.md.
