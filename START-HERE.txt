CASHNOTE WEBSITE v2.5

1. Read README.md and DEPLOYMENT-GUIDE.md.
2. Review ADMIN-SETUP-GUIDE.md before deploying the CMS.
3. Apply render.yaml. The API uses Render Starter + 1 GB Persistent Disk to keep CMS edits/uploads durable.
4. Set ADMIN_PASSWORD (minimum 16 characters) in Render. Keep ADMIN_SESSION_SECRET generated by Render.
5. Deploy both existing Render services.
6. Open https://cashnote-download-api.onrender.com/admin/ to edit copy and upload product media.
7. If you do not upload a video, the animated product-tour motion graphic is displayed automatically.

No separate database is used. CMS data is stored in a small JSON file and media files on the Render disk.
