CASHNOTE WEBSITE v2.6 — GITHUB ASSETS CMS

1. Read README.md, DEPLOYMENT-GUIDE.md and ADMIN-SETUP-GUIDE.md.
2. Push this project to the original CashNote-Website repository.
3. Apply render.yaml. It uses Free Static Site + Free stateless Node API; no disk.
4. Create a Fine-grained GitHub token limited to CashNote-Website with Contents: Read and write.
5. Set CMS_GITHUB_TOKEN, ADMIN_PASSWORD (16+ chars) and ADMIN_SESSION_SECRET (32+ chars) in Render API Environment.
6. Deploy both Render services.
7. Add your image/video files manually to public/assets/images or public/assets/videos, then push them to GitHub.
8. Open https://cashnote-download-api.onrender.com/admin/.
9. Edit text or enter the matching /assets/... path. Admin verifies the file exists.
10. Save creates a GitHub commit for public/cms/content.json and triggers the static website redeploy.

No Render Persistent Disk or separate database is required. Large videos should be embedded from YouTube or another video host.
